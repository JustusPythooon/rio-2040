# RIO 2040

Fertige statische Website fuer GitHub Pages.

## Veroeffentlichen
1. Neues GitHub-Repository erstellen.
2. Den INHALT dieses Ordners hochladen: index.html, assets, README.md und .nojekyll.
3. Settings > Pages oeffnen.
4. Deploy from a branch waehlen.
5. Branch main und / (root) waehlen.
6. Save anklicken.
